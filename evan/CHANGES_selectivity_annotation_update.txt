Changes
-------
1. Dedicated selectivity figures now reserve a separate right-hand white panel for the equation.
   The equation is centered there at 15.5 pt, so it cannot occlude plotted data points.
2. Per-cell selectivity values are printed on every responsive-cell panel in individual_tuning_pages.
   Pure tones: lifetime sparseness S_life.
   Chords: harmonic selectivity SI_harm.
   FM sweeps: direction selectivity SI_dir.
3. The same sound-specific per-cell selectivity value is printed in the tuning-panel title for each
   corresponding sound row in every cell_reports image.
4. Existing statistics, FM signed-log spacing, v2b incomplete-block filtering, output folder structure,
   and selectivity definitions are unchanged.
